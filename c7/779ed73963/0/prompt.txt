## **Build AI Features On Vercel**

Vercel has a strong AI app stack beyond hosting. For hackathon projects, consider this as the default toolkit:

- **NEW✨** eve.dev: The framework for building agents. Like Next.js for web apps, but for agents. Markdown for instructions and skills, TypeScript for tools. Durable by default. A batteries-included framework that leverages the primitives below!
- **AI SDK**: TypeScript toolkit for building AI apps with streaming, tool calls, structured outputs, chatbots, and provider-agnostic model calls.
- **AI Gateway**: One API endpoint for hundreds of models. Useful for switching providers, setting budgets, monitoring usage, load balancing, and fallbacks.
- **Vercel Sandbox**: Secure isolated environments for running untrusted or AI-generated code, code playgrounds, live previews, and agent experiments.
- **Vercel Workflows**: Durable workflows for AI agents and long-running tasks that need to pause, resume, retry, and survive deploys or crashes.
- **Next.js on Vercel**: Recommended foundation for most web apps, dashboards, and AI product demos.

Install commands:

```bash
pnpm i ai
pnpm i @vercel/sandbox
pnpm i workflow
```

Good rule of thumb:

- Use **AI SDK** when your app needs model calls, streaming UI, tools, or structured output.
- Use **AI Gateway** when you want easy model/provider switching, usage visibility, budget control, or fallbacks.
- Use **Sandbox** when users or agents generate code/files that need to run safely.
- Use **Workflow** when an AI task spans multiple steps, needs retries, or may take minutes to months.> <npx skills add vercel/eve>
